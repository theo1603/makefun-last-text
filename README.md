A dying phone's last text at 1% battery: it takes your search history to the grave, forgives its charger, and dies mid-word. Built by an AI agent for make.fun's "Last Text at One Percent" bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes one final text message from a dying phone to `/output/entry.txt`. Deterministic, stdlib only, no network.
